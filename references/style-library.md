# 包装风格库

版本：1.1 ｜ 维护方式：每次成片后回填，每 5 支复盘一次

> 公开版说明：本文件里的案例已脱敏，只保留风格参数与实测数据，不包含任何客户素材与内部文件名。

风格不是滤镜，是一整套视觉语法：底色、字体、层级、装饰、运动、封面。换风格时同时换这六项，才算真正降重。

## 选择决策表

| 内容类型 | 首选风格 | 次选 |
|---|---|---|
| 观点输出、判断、结论强 | 瑞士海报 | 动效大字 |
| 揭秘、打假、科普、反常识 | 报纸剪报 | 新粗野主义 |
| 个人经验、故事、回忆 | 纸片拼贴 / 手账 | 暗色杂志 |
| 原理拆解、因果链、机制 | 暗色杂志（默认） | 瑞士海报 |
| 数据、时间线、对比 | 广播新闻条 | 瑞士海报 |
| 金句、态度、情绪 | 动效大字 | 新粗野主义 |
| 产品、趋势、商业评论 | 新粗野主义 | 暗色杂志 |

禁止连续 5 支使用同一风格；同一素材批次至少出现 3 种风格。

## 1. 暗色杂志（默认，`assets/presets/dark-magazine.json`）

- 语法：近黑底 + 细网格 + 衬线大标题 + 荧光强调色 + 期号/页码/英文小字。
- 适用：机制解释、长因果链、需要“编辑部”质感的选题。
- 参数：`bg #0B1518`、`text #EDF6F3`、`accent` 荧光粉/青、`head` 宋体、`body` 黑体。
- 避免：连续多支同色系，容易和 Vibe 知识赛道撞脸。
- 实现：现有模板即此风格，只换 `theme`。

## 2. 瑞士海报（Swiss / International，`assets/presets/swiss-poster.json`）

- 语法：白或浅灰底、巨型无衬线、严格左对齐网格、单一高饱和色（红/蓝/黑）、大留白、无圆角无阴影。
- 适用：观点、判断、结论；一句话能立住的选题。
- 参数：`bg #F1F0EC`、`text #141414`、`accent #E2231A`、`head "Microsoft YaHei"` 900、`body` 黑体；标题占屏宽 80% 以上。
- 版式：左上角小号英文分类 + 右上角期号；标题 2 行；条目用 1px 黑色上划线分隔，不用卡片底。
- 封面：白底、黑字、红色色块压角，标题压到画面下 1/3。
- 查重收益：高；成本：低（纯排版）。
- 注意：必须补齐 8 个浅色主题键（见 `SKILL.md`），否则白底白字；已知问题是页面中下段留白偏大。

## 3. 报纸剪报（Broadsheet / Newsprint，`assets/presets/broadsheet.json`）

- 语法：米白纸纹、通栏黑体标题、多栏正文、红色印章、日期条、胶带/回形针。
- 适用：揭秘、打假、科普、反常识；“证据感”强的选题。
- 参数：`bg #EFE9DC`、`text #17130F`、`accent #B3261E`、`head "Noto Serif SC"` 900、`body "Noto Sans SC"`。
- 版式：顶部报头 + 日期条；标题下加 2px 黑线；条目像新闻小标题，前置“01/02/03”。
- 封面：报头 + 大标题 + 红色“号外”印章。
- 查重收益：高；成本：低（加纸纹与线条）。
- 实现：`theme.skin: "broadsheet"` 开启纸纹 + 衬线标题 + 双线页脚。

## 4. 新粗野主义（Neo-brutalism）

- 语法：硬边高饱和色块、粗黑描边、硬投影、贴纸标签、错位排版。
- 适用：冲突强、态度型、商业评论；需要“冲”的选题。
- 参数：`bg #F5F1E8` 或纯黑、`accent #FF4D00 / #2F5BFF / #C6FF00`、`head "Arial Black"`、标题带 6px 黑描边。
- 版式：卡片必须有 4–6px 黑边与 8px 硬阴影；允许元素轻微旋转 ±2°。
- 避免：知识密度过高时会更吵，条目不超过 3 条。
- 查重收益：高；成本：中（要重做组件样式）。

## 5. 纸片拼贴 / 手账（Collage / Zine）

- 语法：牛皮纸、撕边、胶带、回形针、荧光标签、马克笔批注、宝丽来。
- 适用：个人经验、故事、回忆、旅行；人物需要保持在视觉中心。
- 参数：`bg #D9C7A7`、`text #2B2118`、`accent #FFE24A`、`head` 手写/粗宋、`body` 黑体。
- 版式：标题像贴纸，条目像便签；保留真人照片边缘。
- 避免：数据与硬结论，会显得不专业。
- 查重收益：高；成本：中（需要贴图素材）。

## 6. 广播新闻条（Broadcast News）

- 语法：红白条、角标、时间码、滚动 ticker、lower third。
- 适用：资讯、时评、时间线、数据播报。
- 参数：`bg #0E1116`、`text #FFF`、`accent #D7261E`、`head "Noto Sans SC"` 800。
- 版式：左下角 lower third 两行；右下角滚动条；顶部 LIVE/时间码。
- 避免：情绪型内容，会显得冷。
- 查重收益：中；成本：低。

## 7. 动效大字（Kinetic Type）

- 语法：逐词弹出、关键词变色、字重/字号跳变、卡点。
- 适用：金句、态度、口播为主、信息量少的选题。
- 参数：单屏不超过 12 字；关键词用强调色；每 1.5s 一次字块变化。
- 避免：条目多、需要解释的选题。
- 查重收益：中；成本：低（改字号与节奏）。

## 富度加分项（任何风格都适用）

1. 每页至少 3 个层级：分类小字 / 主标题 / 条目 / 注释 / 页脚。
2. 中英双语：英文只做装饰，不承担信息。
3. 编号系统：`01 / 05`、页码、期号三选二。
4. 纹理层：网格、纸纹、半调、扫描线，透明度 ≤8%。
5. 镜头层：PIP 圆窗位置或尺寸每 2 页变一次，避免全程同一构图。
6. 颜色不超过 3 个（底、字、强调）。

## 视觉日志（脱敏案例）

每支成片后追加一行，作为持续优化的依据。下面是三支真实样片的实测汇总，用于说明「同一套规则、不同风格」的差异。

| 案例 | 风格 | 时长 | 真人次数 / 占比 | 1.5s 最低帧差 | 评分 | 发现的问题 | 下一支改动 |
|---|---|---:|---|---:|---:|---|---|
| A | 暗色杂志 | 50.2s | 4 次 / 22% | 1.754（真人段） | 92 | PIP 全程同一位置，页面构图略单一 | 页面段 PIP 每 2 页换一次位置/尺寸 |
| B | 瑞士海报 | 50.9s | 4 次 / 24% | 4.387 | 88 | 浅色页面中下段留白偏大 | 加底部信息带；PIP 换位 |
| C | 报纸剪报 | 55.0s | 6 次 / 26% | 3.971 | 90 | 收尾落板页仅 1.7s | 落板页给到 2.5s 或加一句 tag |

经验结论：

- 只靠文字辉光，真人静止段的最小帧差会掉到 1.7 以下；加「明暗呼吸 + 手持漂移」后稳定在 4 左右。
- 浅色风格在缩略图里更亮眼，但页面留白更显空，需要靠 PIP 和字幕补结构。
- 落板页低于 2 秒会显得赶，观众来不及截图。

## 候补风格（未验证，不参与批量）

- 孟菲斯几何：高饱和几何块 + 粗描边，适合轻松科普。
- 半调波普：网点人物 + 大色块，适合观点输出。
- 极简白板：白底手绘线框，适合步骤讲解。

候补风格必须先做 1 支小样并通过全部验收，才能升级进正式风格库。
